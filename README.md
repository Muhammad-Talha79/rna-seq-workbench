# RNA-seq Workbench

[![RNA-seq Workbench CI/CD Pipeline](https://github.com/Muhammad-Talha79/rna-seq-workbench/actions/workflows/ci.yml/badge.svg)](https://github.com/Muhammad-Talha79/rna-seq-workbench/actions/workflows/ci.yml)

A production-grade web application for bulk and single-cell RNA-seq processing, quality control, differential expression analysis, and pathway enrichment.

## Architecture & Stack
- **Backend**: FastAPI, Uvicorn, SQLite, Pytest, Scanpy, GSEAPy, DESeq2, FastQC/MultiQC
- **Frontend**: React, Vite, Tailwind CSS, Recharts
- **Containerization**: Docker, Docker Compose
- **CI/CD**: GitHub Actions
